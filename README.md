# Solanix

Solar generation, recorded so anyone can check it. SOLNX is the protocol token on BNB Smart Chain.

**Solanix Global · Dubai, UAE · [solanix.xyz](https://solanix.xyz)**

This repository is private while the design is still being set. Nothing in it is an offer of tokens, a claim on a power plant, or a promised yield.

## What this is

Solanix records measured solar output and settles activity on a public chain. The product is the record. The token is how the protocol charges for access, fees, and governance.

| | |
|---|---|
| Token | SOLNX |
| Chain | BNB Smart Chain |
| Supply | 1,000,000,000, fixed |
| Presale reference | 1 USDT = 10 SOLNX |
| Site | https://solanix.xyz |

SOLNX is not a share of a solar farm. Energy output, if it is represented at all, is a separate record from the protocol token.
